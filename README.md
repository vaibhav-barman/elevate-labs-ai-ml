# AI/ML Internship — Elevate Labs

This repository contains my task submissions and practical work completed during the **Artificial Intelligence and Machine Learning Internship at Elevate Labs**.

The purpose of this repository is to document my progress in Python-based data analysis, data preprocessing, and machine learning fundamentals through hands-on assignments.

## Repository Overview

Each internship task is organized into its own directory, containing the relevant Jupyter notebooks, task documentation, and supporting resources.

## Technologies and Tools

* **Python** — Programming and data processing
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical computing
* **Matplotlib** — Data visualisation
* **Seaborn** — Statistical visualisation
* **Scikit-learn** — Data preprocessing and machine learning utilities
* **Jupyter Notebook** — Interactive development and experimentation
* **Git and GitHub** — Version control and project documentation

## Tasks

### Task 1 — Data Cleaning and Preprocessing

The first task focuses on preparing a dataset for machine learning.

The work includes:

* Inspecting dataset structure, data types, and summary statistics.
* Identifying and handling missing values.
* Checking for duplicate records.
* Encoding categorical variables.
* Scaling numerical features.
* Visualising data distributions and potential outliers.
* Preparing a reproducible preprocessing workflow.

**Task directory:** `Task-1-Data-Cleaning-Preprocessing/`

The Titanic dataset is used for this exercise.

## Learning Objectives

* Develop practical data preprocessing skills.
* Understand common data quality issues.
* Apply appropriate techniques to numerical and categorical data.
* Explore datasets through visualisation and descriptive statistics.
* Understand reproducibility and data leakage prevention in machine learning workflows.
* Maintain clear documentation and version-controlled project history.

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/vaibhav-barman/elevate-labs-ai-ml.git
cd elevate-labs-ai-ml

python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter notebook
```

Download the dataset from the Kaggle source linked in the Task 1 README and place it in the task's `data/` directory. The dataset is not included in this repository.
